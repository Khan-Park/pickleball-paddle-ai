# 제품 명세 요약 (v0.1)

## 목적
피클볼 패들을 고르기 어려운 사용자가 질문에 답하면, 맞는 패들을 이유와 함께 추천받고 구매 링크로 이어지는 한국어 웹앱.

## MVP 핵심 기능
1. 맞춤 질문: 플레이스타일, 선호 무게, 신체 조건(손 크기·팔 불편), 형태(규격), 가격대. 앞선 답에 따라 후속 질문이 바뀌는 진행형
2. 분석 기반 추천: 답변을 프로필로 바꿔 하드 필터 후 소프트 점수로 상위 3개와 추천 이유 제시
3. 구매 링크: 제품 링크(쿠팡 파트너스 연계 가능). 링크 옆에 대가 표시

## MVP 제외
리뷰·커뮤니티, 중고, 가격 알림, 다국어, 회원 기능, 네이티브 앱

## 추천 로직 원칙
- 하드 필터: 가격대, 대회 인증 필요 여부, 구매 가능 여부
- 소프트 점수: 파워/컨트롤 축(코어 두께, 무게, 형태), 관용성(스위트스팟), 팔 부담(무게 상한, 진동 흡수)
- 설명 가능성: 점수에 쓴 규칙 ID가 추천 이유 문장으로 이어진다 (LLM 없이 템플릿)
- 제휴 수수료는 순위에 영향을 주지 않는다. 엔진은 purchase 필드를 읽지 않는다

## 스펙 해석 기준 (일반적 설명, 출처마다 범위가 다름)
- 무게: 가벼우면 다루기 쉽고 무거우면 파워. 초보는 중간대(대략 7.3~8.4oz) 권장
- 코어: 얇으면(~14mm) 파워, 두꺼우면(16mm~) 컨트롤·안정. 초보는 16mm 이상 권장
- 형태: 표준형은 스위트스팟이 넓고, 길쭉한 형은 리치가 길지만 스위트스팟이 줄어든다. 길이+폭 24인치 이하
- 그립: 손 크기에 맞추고, 중간이면 작은 쪽을 권장
- 인증: 대회용이면 USA Pickleball 승인 여부를 확인. 인증 상태는 바뀔 수 있어 확인일을 함께 표기

## 데이터 원칙
제품 데이터는 제조사 공식 스펙 등 확인된 출처만 사용하고, 출처 URL과 확인일(verified_at)을 기록한다. 확인일이 180일을 넘으면 재확인한다.
