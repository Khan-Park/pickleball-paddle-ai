# M2 기획안: 고르기 편하게 (v0.2, 2026-11-16 결정 반영)

M1(실사용 최소판)은 검수 보완(T-033)까지 마치고 배포했다. M2는 2단계 기획안(docs/plan/phase2.md) 4장의 "고르기 편하게"를 구체화한다. 이 문서는 **할 일과 순서, 사용자가 정할 것**을 정리한 초안이다. 결정이 끝나면 9장에 기록하고 작업 카드로 나눈다.

## 1. 목표
결과 3개만 보고 끝나지 않고, **확신을 갖고 고르고, 다른 사람에게 보여 줄 수 있게** 한다.

### M2 완료 기준(안)
| # | 기준 | 확인 방법 |
|---|---|---|
| 1 | 추천된 제품마다 전체 스펙·출처·확인일·비슷한 제품을 한 곳에서 볼 수 있다 | 화면 테스트, 375px 확인 |
| 2 | 퀴즈 없이도 전체 제품을 형태·가격·승인으로 걸러 볼 수 있다 | 화면 테스트 |
| 3 | 결과를 링크로 공유할 수 있고, 링크에 답변(특히 팔 불편 답)이 들어가지 않는다 | 링크 형식 테스트 |
| 4 | 공유 링크 주소에 개인 식별 정보(지금 workers.dev 하위 도메인)가 드러나지 않는다 | 배포 주소 확인 |
| 5 | 질문 조합 32개 중 제품 2개 미만인 조합이 지금(13개)보다 줄어든다. 시장에 제품이 없는 조합은 사유를 기록한다 | `data:check -- --coverage` |
| 6 | 가격·스펙·승인이 기준일 안이다(배포 전 점검 통과) | `check:release` |

## 2. 지금 상태 (2026-11-16)
- 제품 22개, 모두 판매처(피앤피노)와 네이버 쇼핑 가격 비교 링크가 있다
- **가격 확인일 만료**: 2026-12-17부터 `check:release`가 실패한다. **12월 16일까지 재확인**이 필요하다
- 조합별 부족 13개(기준 2개 이상)
  - 표준형: 10만 이하(1개), 10~20만(0), 20~30만(0)
  - 하이브리드형: 10~20만 대회용(1), 20~30만(1)
  - 길쭉한 형·넓은 형: 10만 이하(0)
- 2·3순위 상세 시트는 이미 있다. 1순위와 같은 카드를 펼친 모양이고, 출처·확인일·비슷한 제품은 없다
- 출처 URL·스펙 확인일은 지금 **브라우저로 보내지 않는다**(`DISPLAY_EXTRA_FIELDS`). 상세 시트에 넣으려면 이 원칙을 바꿔야 한다(결정 D3)
- 실기기 확인이 남아 있다: 시트 닫은 뒤 스크롤, 네이버 쇼핑 링크, 동작 줄이기, 질문 넘길 때 흔들림

## 4. 추천 순서
1. **T-034 가격 재확인**: 기한이 있고, 늦추면 배포가 막힌다
2. **T-024 상세 시트**: 결정 하나(D3)만 있으면 바로 시작할 수 있고, 둘러보기가 이것을 쓴다
3. **T-026 둘러보기**
4. **주소 결정(D2) → T-027 → T-025 공유**: 공유는 주소가 정해진 뒤에 연다(phase2 결정 6)
5. **T-028 다크 모드, T-037 연출 보강**
6. 조사(D): 위 작업과 겹치지 않으므로 언제든. 결과는 결정 자료로만 쓴다

A의 T-035·T-036은 2~5와 병행한다(데이터 파일만 건드린다).

## 6. 위험과 미확인
- **가격 기준일**: T-034가 12월 16일을 넘기면 배포가 막힌다
- **조합 보강의 한계**: 표준형 중가·넓은 형 저가는 국내 판매 제품이 적을 수 있다(미확인). 못 채운 칸은 사유를 남기고 기준을 바꿀지 사용자가 정한다
- **공유 링크와 데이터 변경**: 공유한 제품이 나중에 빠지면 받은 사람 화면에서 그 제품을 "지금은 목록에 없음"으로 보여 줘야 한다(T-025에서 처리)
- **출처 공개(D3)**: 출처 중 해외 판매처·공식몰 링크가 있다. 링크가 깨질 수 있어 가격 재확인 때 함께 본다
- **미확인**: workers.dev 하위 도메인 변경 가능 여부와 영향, 네이버 쇼핑 검색 API 약관·한도, Cloudflare 무료 요금제의 상업 이용 조건, 웹 글꼴 라이선스 원문

## 7. 하지 않는 것 (2단계 원칙 유지)
회원 기능, 리뷰·커뮤니티, 가격 자동 수집, 제품 사진, LLM 호출

## 8. 작업 카드 번호
T-024~T-028·T-032는 phase2 10장 번호를 그대로 쓴다. 새 번호: T-034 가격 재확인 2차, T-035 조합 보강, T-036 보류·미확인 정리, T-037 연출 보강·Lighthouse.
