## 4. 배포본 브라우저 확인(2026-11-18, `acea99f`)
측정: 360px은 창 크기 흉내, 375·768·1024·1440px은 같은 주소의 iframe 폭으로 쟀다. 칸 값 "0"은 가로 스크롤 없음(`scrollWidth` = 폭) + 화면 밖으로 넘친 요소 0건(넘침을 자르는 부모 안의 요소는 셈에서 뺌). 결과 화면은 답변을 넣어 두고, 저장 화면은 저장 1건을 넣어 두고 쟀다(측정 뒤 지움). 브라우저는 어두운 화면이었다.
