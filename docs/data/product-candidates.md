# 제품 후보 목록 v0.2 (2026-11-15) — 검증 전

**판매량 순위가 아니다.** 아래 "인기"는 다나와 `인기상품순` 정렬(다나와 자체 지표)과 리뷰 수에서 읽은 것이다. 스펙은 제조사 공식 페이지에서 사람이 확인하기 전까지 데이터에 넣지 않는다.

## 조사 한계 (확인하지 못한 것)
- 네이버 쇼핑·스마트스토어: 접근 제한으로 인기순을 볼 수 없었다.
- 쿠팡: 봇 차단 화면이 떠서 읽지 못했다(우회하지 않음).
- 피앤피노, 네이버 카페·커뮤니티: 검색 도구에 잡히지 않았다. **등급별(입문/초급/중급/선수) 국내 사용 후기는 0건**이다.
- 따라서 아래 등급은 **가격대·소재·세트 여부로 한 잠정 분류**이며 사용자 데이터가 아니다.
- 다나와 인기순의 앞쪽 일부(타호마)는 `광고` 표기가 붙어 있어 인기와 구분해서 봐야 한다.
