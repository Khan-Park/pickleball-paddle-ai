# T-018 결과 카드 재설계

## 목표
결과 화면을 2단계 구조(리포트형, 7.2)로 바꾼다: 1순위는 크게, 2·3순위는 한 줄 행으로, 행을 누르면 상세 시트. 근거(적합도·이유·스펙)를 한눈에 보이게 한다. 기획: docs/plan/phase2.md 5.4·5.5·7.2·7.6.

## 할 일
1. **결과 상단**
   - "내 조건" 칩: 경력·성향·무게·형태·예산·대회. 칩 줄을 누르면 질문 화면으로(답변 고치기). 팔 불편 답은 칩에 넣지 않는다(공유·캡처로 새지 않게, 팔 불편 안내 문구는 지금처럼 따로 보인다)
   - 제목·안내 문구·대가 표시 페이지 안내(D-022)는 지금 위치와 규칙을 그대로 지킨다
2. **1순위 카드(크게)**
   - 순위·적합도 라벨, 브랜드·모델명, **적합도 막대**(엔진 점수 0~100을 막대 길이로. 숫자는 보여 주지 않음, 막대는 장식이라 라벨 글자로 뜻을 전달)
   - 핵심 이유 1줄(엔진 이유의 첫 문장), 스펙 칩(무게·코어·형태), 가격·확인일, 대회 승인 배지(T-015 `Badge`)
   - **알아 둘 점은 접지 않는다**: 주의가 있으면 요약에 "⚠ 알아 둘 점 N개"와 첫 문장을 보인다(근거를 숨기지 않음)
   - "자세히" 펼치기: 이유 전체, 주의 전체, **스펙 막대 2개**(무게: 가벼움↔묵직함, 코어 두께: 파워↔컨트롤, 값 숫자 함께), 전체 스펙표(길이×폭, 표면)
   - 구매 링크가 있으면 지금의 구매 묶음(대가 표시 + 링크)을 카드 안에 그대로 둔다. 하단 고정 버튼은 링크가 생기는 T-019에서 만든다
3. **2·3순위 행**
   - 순위, 이름, 적합도 라벨, 가격, 승인 아이콘. 제휴 링크가 있으면 행에도 "광고" 배지(D-022: 제목 근처 표시)
   - 누르면 T-015 바텀시트로 그 제품의 전체 카드(1순위와 같은 내용, 펼친 상태)
4. **스펙 막대 범위**: 무게 7.0~9.0oz, 코어 11~17mm에 점을 찍는다(현재 데이터 7.41~8.82oz, 12~16mm가 모두 안에 든다). 범위 밖 값은 끝에 붙인다. "파워↔컨트롤"은 엔진의 코어 해석(얇을수록 파워)과 같은 방향
5. **테스트**: 기존 결과 화면 테스트 24개(대가 표시·승인 배지·조건 완화 등)의 의미를 유지하며 새 구조에 맞게 고치고, 1순위·행·시트·막대·칩·주의 노출 테스트를 더한다

## 수용 기준
- [x] 375px 첫 화면(스크롤 전)에 1순위의 이름·적합도·핵심 이유·가격이 보인다
- [x] 2·3순위 행을 누르면 시트로 전체 정보가 열리고, 닫으면 행으로 포커스가 돌아온다
- [x] 알아 둘 점이 있으면 펼치지 않아도 개수와 첫 문장이 보인다
- [x] 적합도 막대·스펙 막대가 숫자·글자와 함께 보이고 색만으로 뜻을 전하지 않는다
- [x] 대가 표시 규칙(D-022: 제목보다 앞 안내, 카드·행의 "광고", 링크 바로 위 문구)을 지킨다
- [x] 점수 숫자는 보이지 않는다. 구매 링크 유무는 순위에 영향이 없다(기존 테스트 유지)
- [x] `npm run check`·`npm run build` 통과, 375px·360px 브라우저 확인

## 확인하지 못한 것
- 스펙 막대의 범위(7~9oz, 11~17mm)는 지금 데이터에 맞춘 값이다. 범위를 벗어나는 제품이 들어오면 다시 정한다
- 실제 구매 링크가 없어 대가 표시 배치는 테스트로만 확인한다(D-022 이후 계속 미확인)

## 결과 (2026-11-16)
- 테스트: 기존 결과 화면 테스트 24개 중 2개만 고쳤다("보이는 카드 3개" → 보이는 카드 1개 + 행 2개, 시트 안 카드까지 세면 3개). 확인 내용은 그대로. 새 테스트 6개(1순위 요약, 알아 둘 점 노출, 행 → 시트 → 포커스 복귀, 행의 광고 배지, 내 조건 칩, 스펙 막대). 전체 299개 통과
- 브라우저(정적 빌드): 375px에서 1순위 카드와 2·3순위 행이 모두 첫 화면 안(행 아래 끝 762px < 812px). 360px에서 1순위 가격까지 첫 화면 안(450px < 780px), 가로 넘침 없음. 행 → 시트(안쪽 스크롤, 스펙 막대 2개, 포커스는 닫기) → Esc → 포커스가 행으로. 1순위 "자세히 보기"를 펼치면 스펙 막대가 나온다
- 대가 표시 배치는 실제 제휴 링크가 없어 테스트로만 확인했다
- 승인 배지가 T-015 Badge로 바뀌어 글자 앞 "✓"·"⚠"는 화면 낭독기에 읽히지 않는 아이콘이 됐다(글자는 같다)
