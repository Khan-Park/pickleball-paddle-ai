# T-039 토큰 2차 (라임·히어로·문구 규칙)

## 목표
리디자인(M2.5)에 쓸 색·글자 토큰을 추가하고, 대비와 문구·색 규칙을 테스트로 묶는다. 이 카드에서는 화면을 바꾸지 않는다(새 토큰은 다음 카드들이 쓴다). 기획: docs/plan/m2.5-redesign.md 3.7·4장, 7장 T-039 행.

## 정할 값 (기획안 4.1 제안을 대비 계산으로 다듬음, 2026-11-17 계산)
| 토큰 | 밝은 | 어두운 | 쓰임 |
|---|---|---|---|
| `--lime` | `#c5f23a` | `#b8e62e` | 강조 띠·1순위 배지·꾸밈. 글자색 금지 |
| `--on-lime` | `#1e2a44` | 같음(고정) | 라임 위 글자 |
| `--lime-soft` | `#eefbc8` | `#2a3312` | 넓은 강조 바탕 |

| `--on-hero` | `#ffffff` | 같음(고정) | 히어로 위 제목 |
| `--on-hero-muted` | `#c9d6dc` | 같음(고정) | 히어로 위 설명 |
| `--accent-on-hero` | `#3cc39a` | 같음(고정) | 히어로 위 주 버튼 바탕(틸 계열 유지, U1) |

기획안과 달라진 점(계산 근거):
- **히어로 위 주 버튼**: 기존 틸(`#0f6e56`)은 밝은 히어로 바탕과 2.4:1이라 기준 3:1에 못 미친다. 그래서 히어로 위에서만 밝은 틸(`#3cc39a`, 어두운 화면의 틸과 같은 값)과 짙은 글자를 쓴다. 바탕 대비 6.7:1, 글자 7.3:1
- **어두운 히어로**: 제안값 `#0b1e27`은 어두운 바탕(`#0f1520`)과 1.07:1이라 구분이 안 된다(4.3 방침 위반). `#10303a`로 바꾸면 1.31:1이고, 흰 글자는 14.0:1이다
- **덮개 불투명도**: 흰 바탕 위 최악의 경우로 계산하면 흰 글자는 65% 이상, 설명 글자는 75%에서 4.5:1을 넘는다(4.51). 우선 75%로 정하고, 사진을 고르는 T-042에서 다시 본다
