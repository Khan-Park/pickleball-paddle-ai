# T-020 추천 비교표 바텀시트

## 목표
추천 2~3개를 한 화면에서 나란히 비교해 결정할 수 있게 한다. 기획: docs/plan/phase2.md 4장 M1 "추천 비교표", 5.4("비교하기" 버튼)·5.5(바텀시트).

## 할 일
1. **여는 곳**: 결과 화면 제목 줄 오른쪽 "비교하기" 버튼(보조 버튼). 추천이 2개 이상일 때만 보인다. 누르면 T-015 바텀시트
2. **비교표** (375px에서 가로 스크롤 없이)
   - 위쪽: 제품 열 머리(순위 숫자 + 짧은 이름 두 줄까지)
   - 줄: 적합도(라벨) · 무게 · 코어 두께 · 형태 · 길이×폭 · 표면 · 가격 · 대회 승인 · 핵심 이유(첫 문장)
   - 좁은 화면에서 왼쪽 이름 열을 따로 두면 3열이 좁아지므로, **줄 이름을 각 줄 위에 한 줄로** 두고 그 아래 3칸을 놓는다
   - **다른 값만 강조**: 제품끼리 값이 다른 줄은 굵게, 모두 같은 줄은 흐리게 하고 "모두 같음"을 글자로 붙인다(색만으로 구분하지 않음)
   - 표 의미 구조(`<table>`, 열·줄 머리 `<th scope>`)를 지켜 화면 낭독기가 칸을 읽을 수 있게 한다
3. **표 아래**: 각 제품의 "판매처에서 보기"는 두지 않는다(시트 안 버튼이 많아지지 않게). 대신 열 머리를 누르면 그 제품의 상세 시트(T-018 행과 같은 내용)를 연다 — 시트 위에 시트를 겹치지 않도록 비교 시트를 닫고 연다
4. **테스트**: 2개 이상일 때만 버튼, 줄 9개와 열 수, 다른 값 강조·"모두 같음", 열 머리 → 상세 시트 전환, 제휴 제품 열 머리의 "광고" 표시

## 수용 기준
- [x] 추천이 2~3개면 "비교하기"가 보이고, 1개 이하면 보이지 않는다
- [x] 375px·360px에서 표가 가로로 넘치지 않는다
- [x] 다른 값이 있는 줄과 모두 같은 줄이 글자로도 구분된다
- [x] 열 머리를 누르면 비교 시트가 닫히고 그 제품 상세 시트가 열린다(시트를 겹치지 않음)
- [x] 제휴 링크가 있는 제품은 열 머리에 "광고"(D-022)
- [x] 점수 숫자는 보이지 않는다
- [x] `npm run check`·`npm run build` 통과

- 이름이 긴 제품(예: "Anna Leigh Waters Signature C45 Aurelius 16mm")은 열 머리에서 두 줄로 자르면 앞부분만 보인다. 상세 시트에서 전체 이름을 본다

## 결과 (2026-11-16)
- 구현: 표는 ARIA 역할(table·row·columnheader·rowheader·cell)로 만들고, 줄 이름을 각 줄 위 한 줄에 두었다. 1순위 열 머리는 비교 시트를 닫고 화면의 1순위 카드 제목으로 포커스를 옮긴다(시트를 새로 열지 않음). 2·3순위는 비교 시트의 close 이벤트 뒤에 그 순위의 상세 시트를 연다. 이를 위해 2·3순위 행의 시트 열림 상태를 결과 화면이 관리하게 바꿨다
- 테스트 7개 추가(버튼 노출, 9줄 × 3칸, 모두 같음 표시, 2순위 → 상세 시트 1개만, 1순위 → 카드 제목 포커스, 광고 표시, 승인 줄 기준). 전체 314개 통과
- 브라우저(정적 빌드, 360px): 비교표 내용 폭 320px = 보이는 폭(넘침 없음). 2순위 열 머리 → 비교 시트 닫힘 → "2순위 자세히" 시트 하나만 열림. 실제 데이터 조합(3년 이상·파워·예산 상관없음)에서는 9줄 모두 값이 달라 "모두 같음"은 테스트로만 확인했다. 375px은 360px보다 넓어 따로 재지 않았다
