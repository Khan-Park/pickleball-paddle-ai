# T-015 디자인 토큰과 기본 컴포넌트

## 목표
2단계 화면 작업(T-016~T-023)이 같은 재료로 만들어지도록 디자인 토큰(색·글자·모서리·그림자·모션)과 기본 컴포넌트 4종(버튼, 배지, 바텀시트, 스켈레톤)을 만든다. 강조색 코트 청록(D-028)을 반영한다. 기획: docs/plan/phase2.md 6장·7장.

## 할 일
1. **토큰** (`src/app/globals.css`의 CSS 변수와 Tailwind `@theme`)
   - 색: 강조색을 코트 청록으로 바꾼다. 명도 대비 계산(2026-11-16):
     | 토큰 | 값 | 쓰임 | 대비 |
     |---|---|---|---|
     | `accent` | `#0F6E56` | 주 버튼 바탕, 선택 테두리, 진행·적합도 막대, 강조 글자, 포커스 링 | 흰 글자 6.2:1, 바탕 위 글자 5.8:1 |
     | `accent-soft` | `#E1F5EE` | 선택된 선택지·칩 바탕 | 위의 `accent` 글자 5.5:1 |
     | `accent-ink` | `#085041` | 옅은 바탕 위 글자 | 8.3:1 |
     | `accent-bright` | `#1D9E75` | 넓은 장식 면(아이콘 등)만. 막대·글자에는 쓰지 않는다 | 회색 트랙 위 2.7:1이라 막대에 부적합 |
     - 남색·회색·주의(`caution`)·확인(`confirm`)은 그대로 둔다. 확인 초록(`#15803D`)과 청록이 비슷하므로 승인 표시는 아이콘·글자를 함께 쓴다(배지 컴포넌트에서 강제)
   - 글자 크기 6단계(28/22/18/16/14/12)와 줄 간격, 굵기 2단계(400/700)
   - 모서리 3단계(8/16/24px), 그림자 2단계(카드, 시트)
   - 모션: 시간 3단계(120/220/400ms), 곡선 2개. `prefers-reduced-motion: reduce`이면 이동·확대 애니메이션을 끄는 전역 규칙
2. **기본 컴포넌트** (`src/components/ui/`, 새 패키지 없음)
   - `Button`: 주(청록 바탕)·보조(테두리)·텍스트 3종, 크기 2종, 누름 연출(98%). 링크(`next/link`)에도 같은 모양을 쓸 수 있게 클래스 함수(`buttonClass`)를 함께 낸다
   - `Badge`: 확인·주의·중립·광고 4종. 아이콘과 글자를 함께 받는다(색만으로 구분하지 않음)
   - `BottomSheet`: 브라우저 기본 `<dialog>`로 만든다(포커스 가두기·Esc 닫기·배경 비활성화를 브라우저가 처리). 제목, 닫기 버튼, 바깥 누르면 닫기, 닫으면 연 버튼으로 포커스 복귀, 아래에서 올라오는 연출
   - `Skeleton`: 카드 모양 회색 상자, 은은한 깜빡임. 화면 낭독기에는 숨기고, 동작 줄이기면 정지
3. **기존 화면**: 토큰 값만 바뀌므로 지금의 시작·질문·결과 화면이 자동으로 청록이 된다. 기존 화면의 버튼을 새 컴포넌트로 바꾸는 일은 각 화면 카드(T-016·T-018·T-023)에서 한다
4. **확인**: 컴포넌트 단위 테스트. 브라우저에서는 커밋하지 않는 임시 확인 페이지로 375px·동작 줄이기 상태를 본다

## 확인하지 못한 것
- 테스트 환경(jsdom)이 `<dialog>`의 `showModal()`을 지원하는지. 지원하지 않으면 테스트에서만 최소한의 대체 구현을 둔다
- 웹 글꼴은 이 카드에서 다루지 않는다(D-028: 조사 후 결정). 지금 글꼴 지정(`Pretendard` 우선, 없으면 시스템 글꼴)을 유지한다

## 결과 (2026-11-16)
- 테스트 9개 추가(버튼 2, 배지 2, 스켈레톤 1, 바텀시트 4). jsdom 31에 `<dialog>`의 `showModal()`·`close()`가 없어 테스트 파일 안에서만 최소 대체 구현을 둔다
- 브라우저(375px, 커밋하지 않은 임시 페이지): 시트가 화면 아래에 붙어 열리고, 바깥 누르기·실제 Esc 키로 닫히며, 연 버튼으로 포커스가 돌아오고 스크롤 잠금이 풀린다. 콘솔 오류 없음. 기존 질문 화면은 깨지지 않고 진행 막대가 청록이 됐다
- 동작 줄이기: 브라우저 도구로 운영체제 설정을 흉내 낼 수 없어 화면으로는 확인하지 못했다. 빌드된 CSS에 `prefers-reduced-motion` 규칙이 들어간 것만 확인했다
