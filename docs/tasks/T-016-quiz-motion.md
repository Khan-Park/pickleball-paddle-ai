# T-016 질문 화면 개편과 전환 연출

## 목표
질문 화면을 2단계 구조(리포트형, 7.2)와 T-015 컴포넌트로 다시 만들고, 선택·전환에 시각 피드백을 준다. 기획: docs/plan/phase2.md 5.2, 6.1·6.2.

## 할 일
1. **화면 구성** (5.2)
   - 상단: 뒤로 버튼(첫 질문에서는 숨김) + 진행 막대(이어진 막대) + "3/7"
   - 질문 제목(제목 크기 토큰), 보조 설명
   - 선택지 카드: 제목 + 설명 한 줄, 높이 64px 이상. 선택되면 청록 테두리·옅은 청록 바탕·체크 표시
   - 형태 질문(여러 개 선택)만 하단 "건너뛰기"·"다음" 버튼. "다음"·"결과 보기"·"처음부터 다시 답하기"는 T-015 `Button`으로 바꾼다
   - 이어서 답하기 안내 문구는 지금 동작을 유지하고 모양만 맞춘다
2. **연출** (6.2, 새 패키지 없이 CSS)
   | 위치 | 연출 | 시간 |
   |---|---|---|
   | 선택지 누름 | 98% 눌림, 선택 표시(테두리·바탕·체크)가 먼저 보인 뒤 다음 질문으로 | 표시 후 150ms 뒤 이동 |
   | 질문 전환 | 앞으로: 오른쪽에서 밀려 들어옴 + 페이드. 뒤로: 왼쪽에서 | 220ms, ease-out |
   | 진행 막대 | 길이가 부드럽게 늘고 줄어듦 | 400ms |
   - 150ms 기다리는 동안 다른 선택지를 또 누르면 무시한다(두 번 넘어가지 않게). 동작 줄이기 설정이면 기다리지 않고 바로 넘어간다
   - 전환 중에도 포커스 이동(새 질문 제목으로)은 지금처럼 유지한다
3. **테스트**: 기존 질문 화면 테스트 15개를 새 동작(선택 후 지연 이동)에 맞게 고치고, 연타 무시·뒤로 방향·동작 줄이기 즉시 이동 테스트를 더한다

## 수용 기준
- [x] 5.2 구성대로 보이고 375px·360px에서 가로 스크롤·글자 잘림이 없다
- [x] 선택 후 선택 표시가 보인 뒤 다음 질문으로 넘어가고, 연타해도 한 번만 넘어간다
- [x] 앞으로·뒤로 전환 방향이 다르게 보인다(브라우저 확인)
- [x] 동작 줄이기면 지연 없이 넘어가고 이동 애니메이션이 없다
- [x] 키보드로 끝까지 진행할 수 있고, 질문이 바뀌면 포커스가 새 제목으로 간다
- [x] 질문·분기·저장 로직(`src/lib/quiz`)은 바뀌지 않는다. 기존 테스트의 의미를 유지한다
- [x] `npm run check`·`npm run build` 통과

## 결과 (2026-11-16)
- 테스트: 기존 15개를 "선택 후 150ms 뒤 이동"에 맞게 고치고(가짜 타이머), 5개(선택 표시 후 이동, 연타 무시, 마지막 질문에서 결과로 한 번만, 전환 방향, 동작 줄이기 즉시 이동)와 저장 답변으로 형태 질문에서 시작하는 경우 1개를 더했다. 전체 285개 통과
- 구현 중 찾은 문제: 아직 이동하지 않은 상태에서는 화면이 "답하지 않은 첫 질문"을 보여 주므로, 답을 넣는 순간 선택 표시 없이 다음 질문으로 넘어갔다. 선택할 때 지금 질문 위치를 고정해 해결했다(형태 질문 포함)
- 브라우저(정적 빌드): 360px에서 가로 넘침 없음, 선택지 높이 75px. 선택 표시 후 이동, 뒤로 가면 왼쪽에서 들어옴, 포커스가 새 질문 제목으로 이동, 키보드(Tab·Enter)로 진행, 시작부터 결과 화면까지 진행, 콘솔 오류 없음
- 동작 줄이기: 화면으로는 확인하지 못했다(브라우저 도구로 운영체제 설정을 흉내 낼 수 없음). 즉시 이동은 테스트로만 확인했다
- 페이지를 처음 열 때도 진입 연출(오른쪽에서 들어옴)이 한 번 나온다
