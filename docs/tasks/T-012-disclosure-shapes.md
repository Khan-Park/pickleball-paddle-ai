# T-012 대가 표시 보강과 형태 그림

## 목표
구매 링크가 생기기 전에 대가 표시의 틀을 완성하고, 선호 모양 질문에 형태 그림을 넣는다. 설계: docs/design/ui-flow.md 3장, 8장.

## 수용 기준
- [x] 제휴 링크의 대가 표시는 같은 묶음 안에서 **링크보다 먼저** 나온다(이전에는 버튼 아래)
- [x] 추천 결과에 제휴 링크가 하나라도 있으면 **카드보다 먼저** 페이지 안내를 보여 준다. 없으면 보여 주지 않는다
- [x] 문구에 "광고"를 넣고, "받을 수 있습니다" 같은 조건부 표현을 쓰지 않는다
- [x] 제휴가 아닌 일반 링크에는 대가 표시를 붙이지 않고 `rel="sponsored"`도 넣지 않는다
- [x] 선호 모양 질문에 형태 4가지 선 그림(직접 그린 SVG, 화면 낭독기에는 숨김)
- [x] 화면 테스트 추가, `npm run check`·`npm run build` 통과, 브라우저(폭 375px) 확인

## 확인하지 못한 것 (구매 링크를 넣기 전에 사람이 확인)
- **공정위 「추천·보증 등에 관한 표시·광고 심사지침」 원문**: 검색으로 본 것은 법무법인·블로그의 해설이다. 해설에 따르면 2024-12-01 시행 개정으로 표시 위치가 "제목 또는 첫 부분"으로 강화됐고 조건부 표현은 적합하지 않다고 한다. 원문은 https://www.law.go.kr/LSW/admRulInfoR.do?admRulSeq=2100000280130 에서 직접 확인한다.
- **쿠팡 파트너스 약관·가이드의 필수 문구**: 확인하지 못했다. 프로그램이 정한 문구가 있으면 `src/components/result/labels.ts`의 `NOTICE.affiliate`·`affiliatePage`를 그 문구로 바꾼다.
- 지금 문구는 위 해설을 반영한 초안이며 법적 검토를 거치지 않았다.
- 지금은 모든 제품의 `purchase`가 비어 있어 실제 화면에는 대가 표시가 나오지 않는다(테스트로만 확인).
