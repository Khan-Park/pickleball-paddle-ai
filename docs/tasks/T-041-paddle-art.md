# T-041 패들 그림 다듬기

## 목표
제품 사진 대신 쓰는 직접 그린 패들 그림(`ShapeIcon`)을 최종본 수준으로 다듬는다. 크기를 3단계로 늘리고, 히어로·꾸밈에 쓸 공 그림을 추가한다. 기획: docs/plan/m2.5-redesign.md 3.3(이미지), 3.7(라임 규칙), 7장 T-041 행, D-035 (1).

## 그림 방향
- **패들**: 지금의 형태 4종 비율(면 폭·높이)은 그대로 둔다. 시작 화면 그림과 공유 미리보기(`og.png`)가 같은 비율을 쓰기 때문이다. 그 위에 세부를 더한다
  - 면: 옅은 바탕(현재 글자색의 낮은 불투명도)으로 채운다
  - 가장자리 보호대: 굵은 테두리, 안쪽에 가는 선을 하나 더 둔다
  - 목: 면에서 손잡이로 좁아진다
  - 손잡이: 그립 감은 줄무늬와 끝 마개
  - 색은 `currentColor`와 토큰만 쓴다. 지금처럼 부모의 글자색(남색·틸)을 따른다
- **넣지 않는 것**: 제조사 로고·글자·무늬(상표 오인 방지), 제품별 색. 제품별 색은 필요해지면 별도 결정한다
- **크기 3단계**
  - `sm` 24×36: 목록 줄·카드용, 새로 추가. T-046·T-048부터 쓴다
  - `md` 36×54: 질문 선택지, 지금과 같음
  - `lg` 56×84: 시작 화면, 지금과 같음
  - 그림 상자(viewBox 48×72)를 그대로 써서 기존 화면의 자리 크기가 바뀌지 않는다
- **공 그림**: 새 `BallIcon`
  - 라임 바탕에 구멍 무늬를 넣는다. 라임은 꾸밈에만 쓴다는 규칙(3.7)의 "공 그림"에 해당한다
  - 테두리는 `currentColor`라 밝은 바탕에서도 경계가 보인다
  - 이 카드에서는 부품만 만든다. 히어로(T-042)와 홈(T-043)에서 쓴다

## 수용 기준
- [ ] 형태별 `data-shape`가 유지되고, 모르는 형태 값이면 그리지 않는다(기존 테스트 통과)
- [ ] 크기 `sm`·`md`·`lg`가 있고, `md`·`lg`의 가로·세로 크기는 지금과 같다
- [ ] 형태 4종의 면 폭·높이 값이 지금과 같다(테스트로 고정)
- [ ] 패들·공 그림 모두 `aria-hidden="true"`·`focusable="false"`이고, `<text>`·`<image>` 요소가 없다(글자·외부 그림 없음)
- [ ] 그림 안에 고정 색 값이 없고 `currentColor`·`var(--토큰)`만 쓴다(테스트)
- [ ] 밝은·어두운 화면 모두에서 그림의 경계가 보인다(시작 화면·질문 형태 선택지 스크린샷, 사람 확인)
- [ ] 제조사 로고·무늬를 흉내 내지 않았다(사람 확인)
- [ ] `npm run check` 통과, 빌드 통과
