# T-055 filter 경계 케이스 테스트 보강

## 목표
`hardFilter`의 테스트가 덮지 못한 경계 케이스 3건을 테스트로 고정한다. 프로덕션 코드는 바꾸지 않는다.

## 수용 기준
- [ ] 예산에서 `min_krw`만 지정한 경우를 테스트한다: 하한 이상(경계 포함)만 통과, 하한 미만과 가격 없는 제품은 제외
- [ ] 달력에 없는 날짜(`2026-02-30`)인 확인일은 제외되고, 같은 값의 기준일은 `RangeError`를 던지는 것을 테스트한다
- [ ] 확인일이 기준일과 같은 날(0일째)이면 통과하는 것을 테스트한다
- [ ] 새 테스트가 현재 코드에서 통과한다. 통과하지 않으면 코드를 고치지 않고 버그 후보로 보고한다
- [ ] `npm run check` 통과

## 루프
- 검증: `npm run check`
- 최대 반복: 2
- 중단 조건: 같은 실패 반복, 또는 새 테스트가 현재 코드와 어긋나 코드 수정이 필요해질 때
- 사람 확인: 기대값이 의도와 다르다고 판단될 때

- 이번 범위에서 제외: 인증이 필요 없는 요청에서도 기준일 형식이 잘못되면 예외가 나는 동작. 의도인지 확인되지 않아 테스트로 고정하지 않는다(사용자 결정 필요)
