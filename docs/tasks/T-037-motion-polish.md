# T-037 연출 보강·필터 정리·Lighthouse

## 목표
M1 검수에서 M2로 넘긴 연출(phase2 6.2 중 빠진 것)을 넣고, 둘러보기 필터가 화면을 너무 차지하는 문제(T-026 결과)를 정리하고, 배포본의 성능·접근성 점수를 처음으로 기록한다. 기획: docs/plan/m1-review.md 4장 "M2로 넘길 것", docs/plan/m2.md 3장 C, phase2 6.1·6.2·7.8.

## 원칙(phase2 6.1)
- 움직임은 `transform`·`opacity`만, 새 패키지 없이 CSS로. 연출이 조작을 늦추지 않는다
- 동작 줄이기면 전역 규칙(`globals.css`)으로 꺼진다

## 할 일
1. **적합도 막대 채움**(`parts.tsx` FitBar): 막대가 0에서 제 길이까지 채워진다. 폭은 그대로 두고 `scaleX(0→1)`(왼쪽 기준) 500ms, 카드가 떠오른 뒤(300ms 늦게) 시작. 새 키프레임 `bar-fill`
2. **"자세히" 펼침**(`ResultCard.tsx`의 details): 펼칠 때 내용이 살짝 아래에서 떠오르며 나타남(200ms, 이동·투명도만). 높이 자체를 늘이는 연출은 6.1(레이아웃 바꾸는 움직임 금지)과 맞지 않아 하지 않는다. ▾ 회전은 지금처럼
3. **"판매처로 이동합니다" 안내**: "판매처에서 보기"·"다른 곳 가격 비교"를 누르면 화면 아래에 짧은 안내(판매처: "판매처로 이동합니다. 새 창에서 열립니다", 가격 비교: "네이버 쇼핑으로 이동합니다…")가 1초 동안 나타났다 사라진다
   - 새 부품 `ui/Toast`(한 번에 하나, `role="status"`, 하단 고정 바 위에 뜸). 링크 동작(새 창 열기)은 막지 않는다
   - 대가 표시(D-022)는 링크 바로 위 그대로. 안내는 대가 표시를 대신하지 않는다
4. **시트를 아래로 끌어 닫기**(`BottomSheet.tsx`): 위쪽 손잡이·제목 줄을 잡고 아래로 끌면 시트가 손가락을 따라 내려가고(`translateY`), 놓았을 때 100px 이상 내려갔으면 닫고 아니면 제자리로 돌아온다
   - 내용 영역에서는 끌기를 받지 않는다(스크롤과 겹치지 않게)
   - 닫기 버튼·바깥 누르기·Esc는 지금처럼. 끌기는 손가락·마우스 모두(pointer 이벤트)
5. **둘러보기 필터 접기**(`Browse.tsx`): 375px에서 필터가 346px라 목록이 화면 중간 아래에서 시작한다
   - 제안: 필터 3줄을 접을 수 있는 영역으로 만들고 **처음에는 접힌 상태**. 접힌 줄에는 "필터" 버튼과 고른 조건 요약(예: "넓은 형 · 10~20만"), "필터 지우기"
   - 펼침 버튼은 `aria-expanded`. 접어도 고른 조건과 "N개 중 M개"는 계속 보인다
6. **Lighthouse 첫 기록**(결정 필요): 배포본 4개 화면(`/`, `/quiz`, `/browse`, `/result`)의 모바일 성능·접근성·권장 사항·검색 점수를 `docs/plan/m2.md`(또는 `docs/deploy.md`)에 남긴다. 목표치는 첫 측정 후 정한다(phase2 7.8)
   - 측정 방법은 아래 "사용자가 정할 것"
7. **테스트**: 막대·펼침 클래스, 안내가 뜨고 사라짐(가짜 타이머)·링크 기본 동작 유지, 끌기 거리별 닫힘/복귀·내용 영역 무시, 필터 접힘 기본·요약 글자·`aria-expanded`
