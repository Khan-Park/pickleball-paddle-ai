# T-049 둘러보기 비교 담기

## 목표
둘러보기 목록에서 제품을 최대 3개까지 "비교 담기"로 고르고, 아래 고정 비교함에서 "비교하기"를 누르면 T-047 비교 부품(담은 제품 모드)으로 비교한다. 담은 목록은 이 탭에만 제품 id로 보관한다. 기획: docs/plan/m2.5-redesign.md 5.3, 7장 T-049 행.

## 설계
- **담기 버튼**: 목록 줄마다 오른쪽에 둔다
  - 줄 전체가 "자세히 보기" 버튼이라 그 안에 넣을 수 없다. 그래서 줄 옆에 따로 둔다. `ProductRow`는 바꾸지 않는다
  - 글자는 담기 전 "비교 담기", 담은 뒤 "✓ 담음"이다. 상태는 `aria-pressed`로 알리고, 접근 가능한 이름에 제품 이름을 넣는다
  - 터치 영역은 44px 이상이다
- **최대 3개**
  - 3개가 차도 다른 버튼을 비활성화하지 않는다(숨기지 않음, 기획 5.3)
  - 4번째를 누르면 담지 않고 "최대 3개까지 비교할 수 있습니다"를 알린다. 짧은 안내(토스트)와 화면 낭독기용 상태 영역을 함께 쓴다
- **비교함**(새 `CompareTray.tsx`)
  - 1개 이상 담으면 화면 아래에 고정해 보인다
  - 내용: 담은 개수 "담은 패들 N/3", 제품 이름(작은 패들 그림과 함께), "비우기", "비교하기"
  - "비교하기"는 2개 이상일 때만 나온다. 1개일 때는 "1개 더 담으면 비교할 수 있어요"라고 안내한다
  - 데스크톱도 같은 고정 띠이고, 폭은 본문과 같다(최대 72rem)
  - 목록 끝이 띠에 가리지 않도록 아래 여백을 둔다
- **비교 열기**
  - `CompareSheet mode="picked"`로 연다(스펙 7줄, 순위·적합도·이유 없음)
  - 표에서 제품 이름을 누르면 비교 시트를 닫은 뒤 그 제품의 "자세히" 시트를 연다. 시트를 겹치지 않는다(결과 화면과 같은 방식)
- **보관**(새 `src/lib/shared/compare-tray.ts`)
  - `sessionStorage` 키 `pb.compare.tray.v1`에 **제품 id 배열만** 넣는다. 구매·제휴 정보는 넣지 않는다
  - 새로고침해도 유지되고, 탭을 닫으면 사라진다
  - 읽을 때: 지금 데이터에 없는 id와 중복은 버리고, 3개까지만 남긴다. 저장소를 못 쓰면 조용히 화면 상태로만 동작한다
  - 담기·빼기 판정은 순수 함수 `toggleTray(ids, id)` → `{ ids, result: "added" | "removed" | "full" }`로 둔다
- **필터와의 관계**: 담은 제품은 필터로 목록에서 사라져도 비교함에 남는다

## 수용 기준
- [ ] `toggleTray`: 담기·빼기·4번째는 `full`이고 바뀌지 않음(단위 테스트)
- [ ] `loadTray`: 없어진 id·중복을 버리고 3개까지만 남긴다. 저장소 값이 깨져 있으면 빈 목록이다(단위 테스트)
- [ ] 저장소에는 키 `pb.compare.tray.v1` 하나만 쓰고, 값은 id 문자열 배열뿐이다(테스트: 저장된 JSON이 정확히 id 배열)
- [ ] 화면
  - [ ] 담기 버튼에 `aria-pressed`와 제품 이름이 있다
  - [ ] 4번째를 누르면 담기지 않고 안내가 나온다
  - [ ] 1개일 때 "비교하기"가 없고, 2개 이상일 때 있다(테스트)
- [ ] "비교하기"가 담은 제품 모드 비교 표(7줄, 적합도 없음)로 열리고, 제품 이름을 누르면 비교 시트가 닫힌 뒤 상세 시트가 열린다(테스트)
- [ ] 새로 그려도(새로고침 흉내) 담은 목록이 남고, 데이터에 없는 id는 빠진다(테스트)
- [ ] "비우기"를 누르면 비교함이 사라지고 저장소 값도 지워진다(테스트)
- [ ] 375px·1024px에서 가로 스크롤이 없고, 비교함이 목록 마지막 줄을 가리지 않는다(브라우저 측정)
