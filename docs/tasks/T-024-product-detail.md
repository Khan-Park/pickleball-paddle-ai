# T-024 제품 상세 시트

## 목표
추천된 제품마다 **전체 스펙, 스펙 근거(출처 링크·확인일), 비슷한 제품 2개**를 한 곳에서 보게 한다. 둘러보기(T-026)도 같은 상세 화면을 쓰므로 추천 정보 없이도 그릴 수 있게 만든다. 기획: docs/plan/m2.md 3장 B·9장 D3, phase2 4장 M2.

## 지금
- 1순위는 카드 안 "자세히 보기"(추천 이유·알아 둘 점·무게/코어 막대·형태·크기·표면), 2·3순위는 같은 내용을 시트로 연다
- 출처 URL·스펙 확인일은 브라우저로 보내지 않는다(`DISPLAY_EXTRA_FIELDS`). D3로 바뀐다

## 할 일
1. **데이터 필드**(D3): `DISPLAY_EXTRA_FIELDS`에 `sources`, `verified_at`을 넣는다. `notes`(내부 메모)와 `official_source_unavailable`은 계속 보내지 않는다. `result/page.tsx` 주석과 schema-fields 테스트를 고친다. 엔진(`PaddleSpec`)에는 여전히 들어가지 않는다
2. **스펙 근거 영역**(새 컴포넌트): "스펙 근거" 제목 + "스펙 확인 YYYY-MM-DD" + 출처 목록
   - 출처마다 사이트 이름(호스트)과 종류를 적는다: `equipment.usapickleball.org` → "USA Pickleball 승인 목록", 구매 링크와 같은 주소 → "판매처", 그 밖 → 호스트 이름만(예: joola.com). "공식"이라고 단정하지 않는다
   - 새 창, `rel="noopener noreferrer"`. 제휴 링크가 아니므로 대가 표시는 없다
3. **비슷한 제품**(새 순수 함수 `src/lib/shared/similar.ts`)
   - 입력은 `PaddleSpec`만(구매 정보·가격 비교 검색어를 받지 않는다. purity 테스트에 이 파일도 넣는다)
   - 거리 = 무게 차 ÷ 0.5oz + 코어 차 ÷ 2mm + (형태가 다르면 1.5) + (표면이 다르면 0.5). 가까운 2개, 같으면 id 순으로 고정. **가격은 쓰지 않는다**(비슷한 스펙을 보여 주는 것이지 더 싼 것을 찾는 기능이 아니다)
   - 결과 화면에서는 **이번 추천 3개는 뺀다**(이미 화면에 있다)
   - 비슷한 이유를 글자로 보인다: "같은 넓은 형 · 무게 +0.2oz · 코어 같음"
   - 추천 조건(예산·대회 승인)과 무관하게 고른다. 목록 위에 "추천 조건과 상관없이 스펙이 비슷한 제품입니다"를 적고, 가격·승인을 함께 보여 예산·대회 조건에 맞는지 사용자가 볼 수 있게 한다
4. **제품 상세 화면**(새 컴포넌트 `ProductDetail`): 추천 정보(`item`)가 있으면 지금 내용을 그대로, 없으면 추천 이유·적합도 없이 스펙·가격·승인·구매 버튼·스펙 근거·비슷한 제품
5. **배치**
   - 1순위 "자세히 보기"와 2·3순위 시트의 끝에 스펙 근거 → 비슷한 제품 순으로 붙인다
   - 비슷한 제품을 누르면 그 제품의 상세 시트가 열린다(추천 정보 없음). 그 시트 안에서 다시 비슷한 제품을 누르면 **새 시트를 겹치지 않고 내용을 바꾸고**, 위에 "← 이전 제품"을 둔다(시트가 끝없이 쌓이지 않게)
   - 시트 제목: "제품 자세히"
6. **테스트**
   - similar: 자기 자신·제외 목록 제외, 형태가 같은 제품 우선, 결과 고정, 비슷한 이유 글자
   - 상세 화면: 출처 링크가 새 창·`noopener noreferrer`, 종류 표시, 확인일, 추천 정보 없이 그리기
   - 결과 화면: 비슷한 제품에 이번 추천 3개가 없다, 누르면 상세 시트, 시트 안에서 다시 누르면 내용이 바뀌고 "이전 제품"으로 돌아간다
   - schema-fields: 화면용 필드에 `sources`·`verified_at`이 있고 `notes`가 없다
