# T-026 둘러보기·필터

## 목표
퀴즈 없이 전체 제품을 형태·가격·대회 승인으로 걸러 보고, 누르면 T-024의 "제품 자세히" 시트로 본다. 기획: docs/plan/m2.md 3장 B·9장 D4, phase2 7.2(앱형 탐색 일부).

## 할 일
1. **걸러 보기·정렬 순수 함수**(새 파일 `src/lib/shared/browse.ts`)
   - 형태: 여러 개 선택(아무것도 안 고르면 전체)
   - 가격 구간: 하나만 선택. 10만 이하 / 10~20만 / 20~30만 / **30만 넘음** / 전체. 퀴즈 예산 구간과 같은 경계(양끝 포함)를 쓰고, 퀴즈에 없는 "30만 넘음"을 더해 모든 제품에 닿게 한다. 가격 정보가 없는 제품은 "전체"에서만 보인다
   - 대회 승인: "승인 확인된 제품만" 켜고 끄기. 기준은 카드·비교표와 같다(승인 + 확인 180일 이내 + 미래 날짜 아님, `certShort`와 같은 판정)
   - 정렬(D4): 가격 낮은 순, 가격 없는 제품은 끝, 같으면 브랜드·모델 이름 순. **구매 링크·제휴 여부는 받지 않는다**(소스 검사 테스트)
2. **화면** `/browse`(새 페이지, 정적 빌드)
   - 상단: "← 처음으로", 제목 "패들 둘러보기", "N개 중 M개"
   - 필터 칩 3줄(형태 / 가격 / 대회 승인). 칩은 `aria-pressed`로 상태를 알리고 최소 높이 44px. 가로로 넘치면 줄바꿈(가로 스크롤 없음)
   - 목록: 한 줄 행(2·3순위 행과 같은 모양). 이름, 형태·무게·코어, 가격, 승인. 제휴 링크면 이름 앞에 "광고"(D-022)
   - 제휴 링크가 하나라도 있으면 목록 위에 대가 표시 안내(결과 화면과 같은 방식). 지금은 제휴 링크가 없어 나오지 않는다
   - 행을 누르면 "제품 자세히" 시트(T-024). 시트 안 비슷한 제품은 자기 자신만 뺀다
   - 결과가 0개면 "조건에 맞는 제품이 없습니다" + "필터 지우기"
   - 하단 안내: 스펙 기준·가격 변동 문구(결과 화면과 같은 `NOTICE`), "순서는 가격순이며 수수료와 무관합니다"
   - 필터 상태는 화면 안에서만 기억한다(주소·저장소에 남기지 않음). 시트를 닫아도 그대로다
3. **들어가는 길**
   - 시작 화면: "질문 시작하기" 아래(고정 바 안)에 보조 링크 "질문 없이 둘러보기"
   - 결과 화면: 하단 "답변 고치기" 옆에 "전체 둘러보기"
   - 탭바는 넣지 않는다(phase2 7.2: 둘러보기가 생길 때 다시 판단 → 화면이 셋뿐이라 링크로 충분하다고 제안)
4. **테스트**
   - browse: 형태 여러 개, 가격 경계(10만·20만 원 제품이 두 구간에 다 나옴), 30만 넘음, 가격 없는 제품, 승인 180일·미래 날짜, 정렬, 구매 정보 미사용
   - 화면: 칩 누르면 목록·개수가 바뀌고 `aria-pressed`, 0개면 "필터 지우기", 행을 누르면 상세 시트, 시작·결과 화면의 링크
   - 시작 화면 375×812 첫 화면에 기존 요소가 그대로 들어가는지 브라우저로 확인(고정 바가 높아진다)

## 수용 기준
- [ ] `/browse`에서 22개를 가격 낮은 순으로 보고, 형태·가격·승인으로 거를 수 있다
- [ ] 정렬·필터는 구매 링크·제휴 여부를 읽지 않는다(테스트)
- [ ] 행을 누르면 "제품 자세히" 시트가 열린다
- [ ] 시작·결과 화면에서 둘러보기로 갈 수 있다
- [ ] 375px에서 가로 넘침이 없고, 시작 화면 첫 화면 구성이 유지된다
- [ ] `npm run check`·`npm run build` 통과
