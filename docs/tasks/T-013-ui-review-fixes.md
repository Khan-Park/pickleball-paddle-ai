# T-013 화면 코드 리뷰 반영과 대가 표시 규정 준수

## 목표
화면 코드(T-009~T-012) 리뷰에서 나온 10건을 고친다. 대가 표시는 공정위 심사지침과 쿠팡 파트너스 가이드의 원문대로 맞춘다(D-022).

## 수용 기준
- [x] 대회 승인 배지가 엔진과 같은 유효기간(180일)을 쓴다. 오래됐거나 날짜가 미래면 "승인 재확인 필요"
- [x] 예산 완화는 상한만 올리고 최소 예산은 유지한다
- [x] 저장된 예산·팔 불편·대회 답이 선택지에 없는 값이면 기본값으로 바꾸지 않고 다시 묻는다
- [x] 질문이 바뀌면 새 질문 제목으로 포커스가 간다. 질문 영역 전체의 `aria-live`는 뺐다
- [x] 질문 화면이 저장된 답변을 불러온다. "처음부터 다시 답하기"로 지울 수 있다
- [x] 이미 답한 질문에는 "다음"(마지막 질문은 "결과 보기") 버튼이 있다
- [x] 가격 유효기간, 오늘 날짜 함수, 형태 이름을 `src/lib/shared`에 한 번만 정의한다
- [x] 결과 화면에 쓰는 필드만 브라우저로 보낸다(`PaddleDisplay`). 출처 URL과 내부 메모는 보내지 않는다. 엔진 타입 `PaddleSpec`은 점수·필터에 쓰는 필드만 담는다
- [x] 대가 표시(D-022): 제목보다 앞에 "광고"와 표시 문구(큰 글자, 다른 색), 제휴 카드의 제목 근처 "광고", 링크 바로 위 표시 문구. 쿠팡 주소에는 파트너스 권장 문구 그대로. 제휴가 아닌 링크는 표시하지 않음
- [x] 데이터 점검: 쿠팡 주소인데 `is_affiliate`가 false면 오류
- [x] CLAUDE.md 핵심 규칙 3을 규정에 맞게 구체화
- [x] 테스트 추가(244개), `npm run check`·`npm run build` 통과, 브라우저(폭 375px)에서 질문 흐름·이어서 답하기·포커스 이동 확인

## 확인하지 못한 것
- 대가 표시는 실제 화면에서 보지 못했다. 모든 제품의 구매 링크가 비어 있어 테스트로만 확인했다. 링크를 처음 넣을 때 브라우저에서 배치를 확인한다.
- 규정 준수 여부는 원문을 읽고 맞춘 것이며 법률 자문을 거치지 않았다.
- 쿠팡 파트너스의 이용약관·운영정책 전문(활동 금지 사이트 목록, 활동 페이지 등록 의무 등)은 읽지 않았다. 도움말에 따르면 [내 정보]에 활동 페이지를 등록해야 한다.
- 제휴 링크의 `rel`에 `noreferrer`를 넣을지는 정하지 못했다(쿠팡 도움말에 안내가 없다). 지금은 `sponsored noopener`.
