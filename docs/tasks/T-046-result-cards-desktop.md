# T-046 결과 카드 데스크톱 3열

## 목표
1024px 이상 결과 화면에서 추천 1~3순위를 카드 3장으로 나란히 보여 준다. 카드 아래에는 비교 표를 펼쳐 둔다. 모바일(1024px 미만)은 지금 구조(1순위 큰 카드 + 2·3순위 줄 + 시트, D-028)를 그대로 둔다. 무게는 "oz · 약 g"로 함께 적는다(U4). 기획: docs/plan/m2.5-redesign.md 2장 결과 행·3.4·3.7·4.4, 7장 T-046 행, D-037·D-038.

## 설계
- **폭에 따라 한 가지 배치만 그린다**
  - 1024px 이상인지는 새 `useMediaQuery` 훅으로 읽는다
  - 두 배치를 모두 그려 CSS로 숨기지 않는다. 구매 링크·id가 두 벌 생기기 때문이다
  - 결과 화면은 답변을 읽은 뒤 브라우저에서만 그려서, 미리 그린 HTML과 어긋나지 않는다
  - 테스트 환경(폭 정보 없음)은 모바일 배치다. 그래서 기존 테스트가 그대로 돈다
- **데스크톱 카드**(`ResultCard`의 새 모양 `column`, 3장 모두 같은 모양)
  1. 순위 배지
     - 1순위: 라임 바탕에 짙은 글자 "1순위"
     - 2·3순위: 회색 바탕
     - 순위는 글자로 쓰므로 색만으로 구분하지 않는다
  2. 적합도 라벨·막대, "광고"(제휴일 때, 이름 근처), 제품 이름
  3. **강점**: 추천 이유 최대 3개
  4. **유의할 점**: 주의 문장. 없으면 칸을 그리지 않는다
  5. **스펙 4줄**: 무게(oz · 약 g) · 코어 두께 · 형태 · 길이×폭
  6. 가격·대회 승인
  7. 구매 묶음: 대가 표시 문구가 링크 바로 위(지금 부품 그대로). 접지 않는다
  8. "자세히 보기"(펼치기): 스펙 막대·출처·비슷한 제품. 지금 1순위 카드의 펼침과 같다
- **넣지 않는 것**: 특성 배지(파워·스핀 등), 코어 소재, "플레이 특성" 탭, 점수 숫자
- **카드 아래 비교 표**("한눈에 보는 스펙 비교", 2~3개일 때)
  - 비교 시트의 표 부분을 `CompareTable`로 떼어 내 그대로 쓴다(T-047 부품)
  - 데스크톱에서는 히어로의 "비교하기" 버튼을 표로 이동하는 링크로 바꾼다. 같은 비교를 대화상자로 또 띄우지 않기 위해서다
  - 열 머리를 누르면 그 카드의 제목으로 포커스를 옮긴다
- **무게 표기(U4)**
  - 새 `formatWeight(oz)` → "7.9oz · 약 224g". 1oz = 28.3495g로 계산하고 정수로 반올림한다
  - 적용하는 곳: 결과 카드 칩, 데스크톱 스펙 줄, 비교 표, 홈 등록 제품 띠, 둘러보기 목록 줄
  - 스펙 막대(눈금 그림)는 oz 그대로 둔다

## 확인하지 못한 것
- g 환산은 반올림 값이라 "약"을 붙인다. 제조사가 g로 따로 밝힌 값과 1~2g 다를 수 있다
- 데스크톱 카드 3장의 높이가 서로 달라 보일 수 있다. 칸 높이는 맞추되, 내용 길이 차이는 그대로 둔다
