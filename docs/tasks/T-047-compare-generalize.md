# T-047 비교 부품 일반화

## 목표
결과 화면의 추천 비교표(`CompareSheet`)를 공용 부품으로 만든다. 그래서 둘러보기에서 담은 제품(T-049)도 같은 부품으로 비교할 수 있게 한다. 1024px 이상에서는 모든 시트를 아래에서 올라오는 모양 대신 가운데 대화상자 모양으로 보여 준다. 기획: docs/plan/m2.5-redesign.md 4.4(시트)·5.3, 7장 T-047 행.

## 설계
- **두 가지 쓰임**: 한 비교표에 두 종류를 섞지 않는다(타입으로 막는다)
  - `추천`: 결과 화면. 열마다 순위·적합도·핵심 이유가 있다. 제목 "추천 N개 비교"
  - `담은 제품`: 둘러보기. 스펙만 있고, 순위·적합도·핵심 이유 줄이 없다. 제목 "담은 N개 비교"
- **열 개수**: 2개 또는 3개만 받는다. 1개나 4개는 타입 오류이고, 테스트로도 막는다
- **줄**
  - 공통 7줄: 무게·코어 두께·형태·길이×폭·표면·가격·대회 승인
  - 추천일 때만 앞에 "적합도", 뒤에 "핵심 이유"가 붙는다(지금과 같은 9줄)
  - 점수 숫자는 넣지 않는다
- **열 머리를 누르면**: 지금은 순위를 넘기는데, 제품 id를 넘기게 바꾼다. 결과 화면은 받은 id로 순위를 찾아 지금과 똑같이 동작한다
- **"광고" 표시**: 제휴 링크가 있는 제품은 열 머리에 "광고"를 붙인다. 지금처럼 두 쓰임 모두에서 붙인다
  - 기획안 T-047 행의 "구매·제휴 필드 안 읽음(소스 검사)"은 이 표시와 충돌해서 따르지 않는다. 대가 표시 규칙(핵심 규칙 3)이 우선이다
  - 대신 구매 링크 주소(`purchase.url`)는 비교표가 읽지 않는다는 검사를 둔다
- **파일 위치**
  - 비교표는 `src/components/compare/CompareSheet.tsx`로 옮긴다
  - 여러 곳에서 쓰는 `certShort`(대회 승인 짧은 표기)는 `src/lib/shared/cert.ts`로 옮기고, 쓰던 3곳의 import를 바꾼다
- **시트의 데스크톱 모양**(`BottomSheet`, 모든 시트에 해당)
  - 1024px 이상: 화면 가운데 대화상자, 최대 폭 48rem, 네 모서리 둥글게, 나타날 때 옅게 떠오름. 손잡이 막대는 숨긴다
  - 모바일: 지금 그대로 둔다
  - 포커스 이동·닫기·끌어 닫기 동작은 바꾸지 않는다(스타일만)

## 수용 기준
- [ ] 결과 화면 비교의 기존 테스트가 모두 통과한다(9줄, "모두 같음", 열 머리 누르면 상세, 1순위면 카드 제목으로 포커스, 광고 표시, 승인 기준)
- [ ] "담은 제품" 비교: 7줄만 있고, 적합도·핵심 이유·순위 숫자가 없다(테스트)
- [ ] 열이 1개나 4개면 타입 오류다(`@ts-expect-error` 테스트). 실행 중에 잘못 들어와도 표를 그리지 않는다(테스트)
- [ ] 비교표 소스에 `purchase.url`이 없다(소스 검사 테스트)
- [ ] `certShort`를 옮긴 뒤 상세·목록·순위 줄의 승인 표시가 그대로다(기존 테스트)
- [ ] 1024px 이상에서 시트가 가운데 대화상자로 보이고, 375px에서는 지금처럼 아래 시트다(밝은·어두운 화면 스크린샷)
- [ ] 시트의 포커스·닫기·끌어 닫기 기존 테스트 통과
- [ ] `npm run check` 통과, 빌드 통과
