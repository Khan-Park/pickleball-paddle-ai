# T-043 홈 화면 개편

## 목표
시작 화면을 리디자인 시안 방향으로 바꾼다. 짙은 히어로, 등록 제품 띠(D-040), "이렇게 찾아요" 3단계, 브랜드 없는 결과 미리보기 예시를 넣는다. 질문 시작 동작과 신뢰 요소 내용은 그대로 둔다. 기획: docs/plan/m2.5-redesign.md 2장 홈 행·3.1·3.2·3.7·4.4, 7장 T-043 행, D-035·D-038·D-040.

## 화면 순서 (위에서 아래, 모바일·데스크톱 같은 순서)
1. 공통 헤더(T-040)
2. **히어로**(`HeroMedia` 홈 자리, 사진이 없으니 대체 배경)
   - 제목 `h1` "질문 1분, 나에게 맞는 패들 3개"
     - "맞는 패들 3개"에 라임 밑줄을 긋는다. 글자 아래 꾸밈선이라 글자색은 흰색 그대로다(3.7)
     - 데스크톱 글자 크기는 `text-hero-title`
   - 설명 한 줄
   - 형태 그림 순환(`ShapeShowcase`): 데스크톱은 오른쪽 6칸, 모바일은 글 아래. 동작은 지금과 같다
   - 버튼(데스크톱만): 주 "질문 시작하기"(히어로용 밝은 틸), 보조 "패들 둘러보기"(히어로용 테두리 버튼)
3. **신뢰 요소 3개**: 내용은 그대로 두고, 데스크톱에서 3열
4. **등록 제품 띠**(D-040)
   - 제목 "등록된 패들 23개". 개수는 데이터에서 센다
   - 옆에 "전체 둘러보기" 링크 하나. 항목 23개를 각각 링크로 만들지 않는다(같은 링크 23개는 키보드·화면 낭독기에 소음이다)
   - 항목: 브랜드·모델 + 칩(형태·무게 oz·코어 mm). 가격 낮은 순(둘러보기 정렬 함수를 그대로 쓴다)
   - 넣지 않는 것: 구매 링크, 가격, 적합도, 순위
   - 움직임
     - 목록을 두 번 이어 붙이고 CSS로 왼쪽으로 민다(transform만). 한 바퀴는 약 60초
     - 멈춤·재생 버튼을 둔다. 마우스를 올리거나 포커스해도 멈춘다
     - 동작 줄이기면 복사본 없이 손으로 미는 가로 목록으로 바꾸고, 멈춤 버튼을 숨긴다
     - 복사본은 화면 낭독기에서 숨기고 포커스도 받지 않는다(`aria-hidden`·`inert`)
5. **이렇게 찾아요** 3단계
   1. 질문에 답하기 — 6~7개, 1분
   2. 스펙 비교 — 답변 조건과 제품 스펙을 맞춰 봅니다(3.1 문구)
   3. 이유와 함께 3개 — 이유·주의점·판매처
6. **결과 미리보기**: "예시" 표시를 붙인 카드 3장
   - 들어가는 것: 패들 그림(T-041 `sm`), 적합도 라벨, 스펙 칩(무게대·형태·코어)
   - 브랜드·모델 이름, 근거 없는 특성 태그(파워·스핀 등), 점수 숫자는 넣지 않는다
7. 안내 문구(공개된 스펙 기준, 타구감은 사람마다 다름): 지금 문구 그대로
8. 모바일 하단 고정 "질문 시작하기": 지금 그대로 둔다. 1024px 이상에서는 숨기고 히어로 버튼을 쓴다

## 바뀌는 부품
- `Button`에 히어로용 모양 2개(`hero`, `heroSecondary`)를 추가한다
  - 포커스 링 색을 공통 클래스에서 모양별 클래스로 옮겨, 히어로 위에서는 `--focus-on-hero`가 확실히 적용되게 한다
  - 기존 모양의 생김새는 바뀌지 않는다
- `StartButton`에 모양을 고르는 값(`variant`)을 추가한다. 기본값은 지금 모양 그대로다
- 본문 폭: 1024px 이상에서 최대 72rem으로 넓혀 헤더와 맞춘다. 모바일은 지금처럼 한 열이다

## 수용 기준
- [ ] 화면에 "AI"·"인공지능"이 없다(T-039 소스 검사)
- [ ] 신뢰 요소 3개의 내용이 그대로다(기존 테스트)
- [ ] 결과 미리보기 영역에 `paddles.json`의 브랜드명이 0건이고 "예시" 표시가 있다(테스트)
- [ ] 등록 제품 띠
  - [ ] 데이터 전체 개수가 들어가고, 가격 낮은 순이다(테스트)
  - [ ] 구매 링크·가격·적합도·순위가 없다(테스트: 띠 안에 판매처 주소·"원"·적합도 라벨 0건)
  - [ ] 멈춤 버튼으로 멈추고 다시 움직인다(`aria-pressed`, 테스트)
  - [ ] 복사본은 `aria-hidden`이고 `inert`이며, 화면 낭독기는 항목을 한 번씩만 읽는다(테스트)
  - [ ] 동작 줄이기면 복사본·멈춤 버튼이 없는 가로 목록이다(테스트)
- [ ] 히어로 제목은 `h1` 하나이고, 히어로 안의 글자·버튼은 히어로 토큰을 쓴다(라임 글자 없음, T-039 검사)
- [ ] 모바일 하단 고정 시작 버튼이 있고, 히어로 버튼은 1024px 이상에서만 보인다
- [ ] "질문 시작하기"는 어느 버튼으로 눌러도 이전 답을 지우고 질문으로 간다(기존 동작)
- [ ] 375px·1024px·1440px, 밝은·어두운 화면 스크린샷에서 겹침·가로 스크롤이 없다(띠는 자기 영역 안에서만 넘침, 브라우저 확인)
- [ ] `npm run check` 통과, 빌드 통과

## 확인하지 못한 것
- 사진이 들어오면 모바일은 세로형, 데스크톱은 가로형으로 바꿔 보여 줘야 한다(`<picture>`). 사진을 넣는 커밋에서 한다. 지금은 대체 배경 하나다
- 무게 "약 g" 병기(U4)는 무게 표기 공용 함수를 만드는 카드(T-046)에서 띠까지 함께 바꾼다. 이번에는 oz만 쓴다
- 띠의 흐르는 속도가 적당한지는 사용자가 판단한다
- 시작 화면 성능(LCP) 변화는 T-053에서 잰다(M2 기록 100점)
