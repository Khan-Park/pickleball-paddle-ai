# T-023 시작 화면 개편

## 목표
첫 화면에서 "무엇을 해 주는 앱인지, 왜 믿을 만한지"를 한눈에 보여 주고 바로 시작하게 한다. 기획: docs/plan/phase2.md 5.1·6.2·7장.

## 할 일
1. **구성** (5.1)
   - 상단 바: 앱 아이콘(지금의 `icon.svg`와 같은 그림) + "패들 추천". 서비스 이름이 정해지면 바꾼다(미정, D-028 도메인 결정과 함께)
   - 제목(28px): "질문 1분, 나에게 맞는 패들 3개" / 보조: "스펙 근거로 이유와 함께 보여 드립니다"
   - **형태 그림 영역**: 형태 4가지(표준형·넓은 형·하이브리드형·길쭉한 형) 그림을 크게 나란히 두고 2초마다 하나씩 강조(테두리·이름 굵게). 동작 줄이기면 강조가 멈춘다. 그림은 장식이라 화면 낭독기에는 숨기고 "형태 4가지를 비교합니다"만 읽힌다
   - **신뢰 요소 3개를 칩으로**: "스펙 근거" · "수수료와 무관한 순위" · "대회 승인 확인". 칩마다 한 줄 설명은 지금 문구(POINTS)를 짧게 줄여 아래에 둔다
   - **하단 고정 "질문 시작하기"**(주 버튼, T-015 `buttonClass`). 누르면 지금처럼 탭에 남은 답변을 지운다(T-014). 아래 안내 문구(스펙 기준·타구감 차이)는 지금 문구를 유지한다
2. **등장 연출** (6.2): 제목 → 그림 → 칩 → 버튼 순으로 떠오르며 나타남(400ms, 80ms 간격). 동작 줄이기면 전역 규칙으로 꺼진다
3. **분석 중 화면 그림과 맞추기**: 분석 중 화면(T-017)의 패들 선 그림을 같은 선 두께·모서리로 다듬는다(T-017 결과 보고에서 "작고 수수하다"는 지적)
4. **질문 화면 첫 진입 연출**: 페이지를 처음 열 때도 질문이 오른쪽에서 들어오는 연출(T-016 결과 보고)은 시작 화면에서 넘어올 때 자연스럽게 보이므로 그대로 둔다 — 바꾸지 않음
5. **테스트**: 시작 버튼이 답변을 지우는 기존 테스트 유지, 형태 4개·칩 3개, 강조 순환(가짜 타이머), 동작 줄이기면 강조 멈춤, 그림 숨김

## 결과 (2026-11-16)
- 화면: 앱 아이콘 + "패들 추천", 제목 "질문 1분, 나에게 맞는 패들 3개", 형태 4가지 큰 그림(2초마다 강조, 동작 줄이기면 멈춤), 신뢰 요소 3개(✓ 아이콘 + 제목 + 한 줄), 안내 문구, 하단 고정 "질문 시작하기"(T-015 버튼 모양, 누르면 저장된 답변 지움). 위에서부터 80ms 간격으로 떠오르며 나타남
- 분석 중 화면 그림을 키우고(160×128) 형태 그림과 같은 비율의 선 두께·모서리로 다듬었다. 공에는 밝은 청록 면 + 남색 테두리
- 테스트 4개 추가(형태 4개와 2초 순환, 그림 숨김과 한 문장 안내, 동작 줄이기면 강조 고정, 시작 화면 제목·신뢰 요소 3개·시작 링크·느낌표 없음). 기존 시작 버튼 테스트는 그대로 통과. 전체 324개
- 브라우저(정적 빌드): 375×812에서 제목 88~161px, 형태 그림 252~406px, 신뢰 요소 438~633px, 시작 버튼 760~812px로 모두 첫 화면 안. 360×740에서 신뢰 요소 아래 끝 639px, 시작 버튼 688~740px로 겹치지 않음. 가로 넘침 없음, 콘솔 오류 없음. 강조가 2초 뒤 표준형 → 넓은 형으로 바뀜
- 확인 과정에서 알게 된 것: 브라우저 창이 숨겨진 상태에서는 스크린샷이 최신 화면을 그리지 못한다(연출이 끝나 투명도 1인데도 빈 화면으로 찍힘). 그래서 위치·투명도는 수치로 확인했다
- 페이지 파일(page.tsx)은 Next 규칙상 정해진 것만 내보낼 수 있어 신뢰 문구 상수를 내보내지 않는다
