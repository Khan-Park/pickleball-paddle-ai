# T-051 공유받은 화면·404·분석 중 새 모양

## 목표
M2.5에서 아직 예전 모양인 세 화면(공유받은 화면, 404, 분석 중)을 새 색·패들 그림·히어로에 맞춘다. 동작과 규칙(공유 링크 해석, 분석 중 시간)은 바꾸지 않는다. 기획: docs/plan/m2.5-redesign.md 2장(분석 중·공유받은 화면·404 행), 7장 T-051 행.

## 설계
- **공유받은 화면**(`Shared.tsx`)
  - 순서: 헤더 → (제휴 링크가 있으면) 대가 표시 → 히어로 띠(`HeroMedia slot="result"`) → 목록. 대가 표시는 지금처럼 `h1` 앞이다
  - 히어로 안 제목: "공유받은 추천 패들 N개"(읽은 제품이 없으면 "공유받은 추천 패들"). 그 아래 지금 안내 "공유한 사람의 답변은 담겨 있지 않습니다…"
  - 비교 연결(기획의 "선택" 항목, 넣는다): 읽은 제품이 2~3개면 히어로에 "비교하기" 버튼
    - 둘러보기 비교함과 같은 `CompareSheet mode="picked"`(스펙 7줄, 순위·적합도·이유 없음). 답변이 없으므로 적합도는 보여 줄 수 없다
    - 표에서 제품을 고르면 비교 시트를 닫은 뒤 "자세히" 시트를 연다(결과·둘러보기와 같은 방식)
  - 폭: 1024px 이상에서 본문 폭을 넓히고(`lg:max-w-6xl`), 제품 줄을 3열 격자로 둔다. 모바일은 지금처럼 한 열
  - 그대로 둘 것: 순위 번호, 없어진 제품 안내, "나도 질문에 답하고 추천받기", 둘러보기 링크, 아래 안내 문구
- **404**(`not-found.tsx`)
  - 패들 그림 하나(`ShapeIcon` 표준형 `lg`)와 공(`BallIcon`)을 제목 위에 둔다. 장식이라 화면 낭독기에는 숨긴다
  - 제목·설명 글자를 토큰 크기(`text-title`, `text-body`)로 맞춘다. 문구는 그대로
  - 버튼: "처음 화면으로"(주 버튼) + "패들 둘러보기"(보조 버튼)
- **분석 중**(`Analyzing.tsx`)
  - 직접 그린 예전 패들 선 그림을 T-041의 `ShapeIcon`(표준형 `lg`)과 `BallIcon`으로 바꾼다. 움직임(`animate-paddle-swing`, `animate-ball-bounce`)은 그대로 쓴다
  - 단계 문구 3개, 실제 제품 수, 건너뛰기, 시간 규칙(`analyzing-flag.ts`), 동작 줄이기 처리는 바꾸지 않는다
  - "AI 분석" 같은 문구는 쓰지 않는다(지금도 없음, copy.test.ts)

  - [x] 제목이 읽은 제품 수를 반영한다(테스트)

  - [x] 비교 표에서 제품을 고르면 비교 시트가 닫힌 뒤 상세 시트가 열린다(테스트)
  - [x] 대가 표시가 `h1`보다 DOM 앞이다(기존 헤더 순서 테스트)

- [x] 분석 중: 새 패들 그림(`ShapeIcon`)과 공 그림이 보이고, 기존 시간·건너뛰기 테스트가 통과한다

## 결과 (2026-11-18)
- 공유받은 화면
  - 대가 표시 → 히어로 띠(제목 "공유받은 추천 패들 N개", 안내, 2~3개면 "비교하기") → 제품 줄 순서
  - 비교는 `CompareSheet mode="picked"`(스펙 7줄, 적합도 없음)이고, 고른 제품은 비교 시트를 닫은 뒤 상세로 연다
  - 1024px 이상은 본문 폭 6xl, 제품 줄 3열
  - 브라우저에서 보니 데스크톱에서 "나도 질문에 답하고 추천받기"가 본문 전체 폭(약 960px)으로 늘어나, 데스크톱 폭을 24rem로 제한했다(모바일은 전체 폭 그대로)
- 404: 표준형 패들 그림 + 공 그림(화면 낭독기에 숨김), 토큰 글자 크기, "처음 화면으로"·"패들 둘러보기" 두 버튼. 문구는 그대로
- 분석 중: 직접 그린 예전 패들 선 그림을 `ShapeIcon`(표준형 lg) + `BallIcon`으로 바꾸고, 기존 흔들기·튀기 움직임을 그대로 붙였다. 문구·시간 규칙·건너뛰기는 그대로
- 테스트: 기존 테스트는 고치지 않고 통과했다. 추가한 것은 공유 3개, 분석 중 1개, 404 1개(새 파일). 전체 574개 통과, 빌드 통과(`out/404.html` 있음)
- 브라우저 측정(로컬 빌드)
  - 공유받은 화면 1024px: 제목 "공유받은 추천 패들 3개", 제품 줄 3열(각 309px, 같은 높이 119px), 비교 시트 열림(모드 picked, 7줄), 시작 버튼 폭 384px, 가로 스크롤 없음
  - 공유받은 화면 375px: 한 열, 시작 버튼 폭 335px, 가로 스크롤 없음. 스크린샷으로 히어로·비교하기·제품 줄이 겹치지 않는 것을 봤다
  - 404(`/abc`): 404 상태, 그림·제목·링크 2개(`/`, `/browse`). 375px 스크린샷 확인, 375px·1024px 가로 스크롤 없음
  - 분석 중은 브라우저에서 보지 않았다(1.2초 이하로만 나온다). 그림 교체는 테스트로만 확인했고, 움직임은 사용자가 확인한다
