# T-019 판매처 링크와 가격 비교 연결

## 목표
결과에서 바로 사러 갈 수 있게 한다: 사람이 확인한 국내 판매처 1곳 링크와 "다른 곳 가격 비교" 링크(D-028). 둘 다 제휴가 아니므로 대가 표시 대상이 아니다(규칙 3, D-022). 기획: docs/plan/phase2.md 4장 M1·8.1.

## 할 일
1. **판매처 링크 데이터**
   - 22개 제품의 `purchase`에 국내 판매처(피앤피노) 상품 페이지를 `{ url, is_affiliate: false }`로 넣는다. 주소는 각 제품 `sources`에 이미 있는 그 판매처 주소를 쓴다
   - 2026-11-16 가격 재확인 때 22개 모두 판매 중이고 우리 모델(코어·형태) 옵션이 살 수 있는 상태임을 확인했다(일부 색상만 품절)
   - 데이터 점검 추가: 일반 판매처 링크는 `sources`에 있는 주소여야 한다(사람이 확인한 페이지로만 보낸다). 어긋나면 오류
2. **가격 비교 링크**
   - 가격 비교 사이트의 검색 결과로 보낸다. 검색어는 제품별로 데이터에 둘 수 있게 하고(`compare_query`, 선택), 없으면 "브랜드 모델 피클볼"로 만든다
   - 사이트는 아래 "결정 필요"에서 정한다
3. **화면**
   - 1순위 카드: "판매처에서 보기 ↗"(주 버튼) + "다른 곳 가격 비교 ↗"(보조 버튼). 가격 옆 "판매처 가격과 다를 수 있음"
   - 하단 고정 바: 스크롤해도 1순위의 "판매처에서 보기"가 화면 아래에 남는다(엄지 영역, 7.2). 1순위 카드의 버튼이 화면에 보이는 동안은 숨겨 같은 버튼이 두 번 보이지 않게 한다
   - 2·3순위 시트: 같은 두 버튼
   - 새 탭, `rel="noopener noreferrer"`. 버튼 이름에 제품명과 "새 창"을 화면 낭독기용으로 넣는다
   - 제휴 링크가 들어오면(M3) 지금의 대가 표시 묶음이 그대로 동작한다(하단 고정 바에도 같은 규칙 적용: 제휴면 바로 위에 대가 표시)
4. **테스트**: 링크 데이터 점검(출처와 일치), 비교 검색어 생성, 버튼·하단 바 노출, 제휴가 아닌 링크에 대가 표시 없음, 하단 바의 제휴 대가 표시

## 결정 필요: 가격 비교 사이트
| 후보 | 확인 결과(2026-11-16) |
|---|---|
| 다나와 | 검색 주소 `https://search.danawa.com/dsearch.php?query=…` 동작. 피클볼 패들은 가격비교 묶음이 없고("가격비교 0") 판매 상품 목록과 광고만 나온다. 예: 붐스틱 ST 4건, JOOLA Essentials 0건 |
| 네이버 쇼핑 | 판매처가 가장 많을 것으로 보이나 확인하지 못했다(이 브라우저에서 안전 제한으로 열리지 않음). 흔히 알려진 검색 주소는 `https://search.shopping.naver.com/search/all?query=…`(미확인) |

결정(사용자, 2026-11-16): 네이버 쇼핑. 검색 주소가 실제로 열리는지는 사용자가 휴대폰에서 확인해야 한다(미확인). 다나와는 결과가 빈약해 두지 않는다.

## 결과 (2026-11-16)
- 데이터: 22개 모두 `purchase`에 피앤피노 상품 페이지(`sources`의 주소)를 `is_affiliate: false`로 넣었다. 새 점검: 제휴가 아닌 판매처 링크가 `sources`에 없으면 오류. `compare_query`(선택) 필드를 스키마에 추가했고 지금은 아무 제품에도 넣지 않았다(기본 검색어 "브랜드 모델 피클볼")
- 화면: 1순위 카드와 2·3순위 시트에 "판매처에서 보기 ↗"(주)·"다른 곳 가격 비교 ↗"(보조). 가격 옆 "판매처 가격과 다를 수 있음". 1순위 구매 묶음이 화면 밖으로 나가면 하단 고정 버튼(제휴면 대가 표시 포함)
- 테스트 8개 추가(데이터 점검 2, 비교 주소 2, 버튼·대가 표시 없음 2, 하단 바 2). 기존 점검 테스트의 링크 도우미가 새 규칙에 맞게 출처에 주소를 넣도록 고쳤다. 전체 307개 통과, check:release 통과
- 브라우저(정적 빌드, 375px): 두 버튼 주소·새 탭·rel 확인. 결과 화면이 짧으면(1317px) 끝까지 내려도 1순위 버튼이 보여 고정 버튼이 뜨지 않고, "자세히 보기"를 펼쳐 길어지면 뜬다(화면 아래 713~812px). 위로 올리면 사라진다. 고정 버튼(99px)이 마지막 줄을 가리지 않게 아래 여백을 128px로 늘렸다
- 미확인: 네이버 쇼핑 검색 주소가 실제로 열리는지, 판매처·가격 비교 사이트로 바로 링크하는 것의 약관상 문제
