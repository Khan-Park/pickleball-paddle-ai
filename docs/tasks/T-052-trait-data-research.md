# T-052 특성 데이터 조사(조사만)

## 목표
컨트롤·파워·스핀·안정성·기동성 같은 "플레이 특성" 값을 **출처가 있는 형태로** 얻을 수 있는지 조사한다. 시안의 레이더·특성 막대를 넣을 수 있는지 판단할 근거 자료를 만드는 것이 목적이다. 수집·데이터 반영·화면 반영은 하지 않는다. 결과를 보고 사용자가 정한다. 기획: docs/plan/m2.5-redesign.md 6장, 3.4, 7장 T-052 행.

## 대상
- 우리 데이터 23개 제품, 13개 브랜드(`data/paddles.json`): JOOLA 5, Franklin 3, NOX 2, Six Zero 2, Friday 2, 11SIX24 2, Spartus·Luzz·Selkirk·Picklepoppers·STAR·Vatic Pro·Honolulu 각 1
- 특성: 컨트롤, 파워, 스핀, 안정성(트윈웨이트 등), 기동성(스윙웨이트 등). 다른 이름의 특성(예: "pop", "feel")이 나오면 그대로 기록한다

## 조사 질문
1. **제조사 공식 표기**: 13개 브랜드 중 공식 제품 페이지에 특성 등급·막대·점수를 적는 곳은 어디인가
   - 척도(1~10, 막대 5칸 등)와 정의가 공개돼 있는가, 브랜드끼리 비교할 수 있는가
   - 우리 23개 모델 중 몇 개에 값이 있는가(모델별 표)
2. **독립 측정치**: 같은 장비·같은 방법으로 여러 제품을 측정해 공개하는 연구실·리뷰 매체가 있는가
   - 측정 항목(스윙웨이트, 트윈웨이트, 스핀 RPM, 볼 속도 등)과 측정 방법 공개 여부
   - 우리 23개 모델을 몇 개 덮는가(모델별 표)
   - 이용 조건: 인용·수치 재게재를 허용하는가, 상업 사이트(제휴 링크가 있는 사이트)에서도 되는가. 약관 원문 위치
3. **스펙에서 계산하는 방법**(무게·코어로 기동성 추정 등): 업계에서 쓰는 공개 공식이 있는지만 기록한다. 핵심 규칙 2(추정값 금지)와 충돌하므로 기본은 제외다. 판단은 하지 않는다
