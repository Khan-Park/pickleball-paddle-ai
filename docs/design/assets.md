# 사진·그림 자산 기록

히어로 사진 등 외부에서 받은 그림 파일마다 아래 표에 한 줄씩 남긴다(T-042, docs/plan/m2.5-redesign.md 3.3). `src/lib/shared/hero-photos.ts`에 넣은 파일은 이 표에 **파일 경로가 그대로** 있어야 한다(`HeroMedia.test.tsx`가 검사한다).

- 라이선스 해석은 법률 자문이 아니다. 원문 확인은 사용자가 하고, 애매하면 전문가에게 확인한다
- 브랜드 로고·제품명이 보이거나 알아볼 수 있는 얼굴이 있는 사진은 쓰지 않는다
- 직접 그린 그림(`ShapeIcon`, `BallIcon`, 히어로 대체 배경, 앱 아이콘)은 외부 자산이 아니라서 이 표에 적지 않는다

## 사진을 넣을 때 확인할 것
1. 라이선스 원문을 사용자가 열어 상업 이용·수정(자르기·덮개) 허용을 확인했다
2. 로고·제품명·알아볼 수 있는 얼굴이 없다
3. WebP로 바꾸고 크기별 파일을 만들었다. 폭·높이를 사진 목록에 정확히 적었다
4. 사진에서 가장 밝은 부분 위에 히어로 글자를 올려 두 모드에서 읽히는지 사람이 확인했다(위 표 "사진 위 글자 확인")
5. 배포 뒤 시작 화면 성능(LCP)을 T-053에서 잰다
