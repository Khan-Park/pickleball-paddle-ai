# 소프트 점수화 설계 (v0.1 초안, 2026-11-14)

하드 필터(예산·대회 인증)를 통과한 제품에 사용자 성향과의 **적합도**를 매겨 상위 3개를 이유와 함께 보여 준다. LLM은 쓰지 않는다(D-003). 점수에 쓴 규칙이 그대로 추천 이유 문장이 된다.

## 1. 한계를 먼저 밝힌다 (이 설계의 전제)
- 제품 스키마에는 **무게, 코어 두께, 형태, 길이·폭, 표면**만 있다. 스윙웨이트, 밸런스, 진동 흡수, 그립 크기, 스핀·파워 실측값은 없다.
- 그래서 점수는 **스펙에서 추정한 경향**이다. 실제 타구감을 측정한 값이 아니다. 화면에도 "스펙 기준 추천"으로 표기한다.
- 아래 임계값은 소매점·브랜드 가이드의 일반적 설명에서 가져온 **초기 가설**이다(판매처 자료라 편향 가능, 출처마다 범위가 다름). 실제 제품 데이터와 사용자 피드백으로 보정한다.
- 모든 숫자는 한 파일(`scoring-config.ts`)에 모으고 `SCORING_VERSION`을 결과에 남겨, 나중에 바꿔도 비교할 수 있게 한다.

## 2. 입력: UserProfile 확장 (T-003)
| 필드 | 값 | 질문 예시 |
|---|---|---|
| skill_level | beginner / intermediate / advanced | 피클볼(또는 라켓 스포츠) 경력은? |
| play_style | control / balanced / power | 더 중요한 것은 정확한 컨트롤인가, 강한 파워인가? |
| weight_preference | light / medium / heavy / no_preference | 가벼운 패들이 좋은가, 묵직한 쪽이 좋은가? |
| arm_discomfort | boolean | 팔·손목·팔꿈치가 불편한 적이 있는가? |
| preferred_shapes | 형태 목록(선택) | 선호하는 형태가 있는가? |

- **성별은 점수에 쓰지 않는다.** 무게·형태에 직접 영향을 주는 것은 손 크기, 근력, 스윙 속도다(분석 문서 제안).
- **그립 크기는 점수에 쓰지 않는다.** 스키마에 데이터가 없고, 제품마다 여러 사이즈로 나온다. 결과 화면의 "그립 고르는 법" 안내로 다룬다.

## 3. 점수 축 (모두 0~1)
**3.1 파워/컨트롤 적합도 (power_control)**
제품의 파워 경향 `lean`(-1 컨트롤 ~ +1 파워)을 스펙에서 계산한다.
- 코어: `clamp((15 - core_mm) / 2, -1, 1)` (13mm 이하 +1, 15mm 0, 17mm 이상 -1)
- 무게: `clamp((weight_oz - 7.9) / 0.8, -1, 1)` (7.1oz -1, 7.9oz 0, 8.7oz +1)
- 형태: elongated +0.6, hybrid 0, standard -0.3, widebody -0.5
- `lean = 0.45*코어 + 0.30*무게 + 0.25*형태`
- 사용자 목표: control -0.6, balanced 0, power +0.6 → `적합도 = max(0, 1 - |lean - 목표| / 1.2)`

**3.2 관용성 (forgiveness)** — 빗맞아도 덜 흔들리는 정도
- `0.6*형태점수 + 0.4*clamp((core_mm - 13) / 5, 0, 1)`; 형태점수: widebody 1.0, standard 0.85, hybrid 0.6, elongated 0.3

**3.3 팔 부담 (arm_comfort)** — `arm_discomfort`가 참일 때만 계산
- 무게대 점수: medium 1.0, light 0.7(너무 가벼우면 진동이 더 느껴질 수 있다는 설명이 있음), heavy 0.2
- 코어 점수: 16mm 이상 1.0, 14~16mm 0.5, 14mm 이하 0
- `0.5*무게대 + 0.5*코어`
- 진동 흡수 자체는 데이터가 없어 평가하지 못한다. 문구는 "팔 부담을 줄이는 데 도움이 될 수 있는 사양"까지만 쓴다(CLAUDE.md 규칙 5). 의학적 효과를 단정하지 않는다.

**3.4 무게 선호 (weight_preference)** — 선택 시에만. 구간 안이면 1, 밖이면 0.5oz당 0.5씩 감점(하한 0)
- 구간(초기 가설, 출처마다 다름): light < 7.3oz, medium 7.3~8.4oz, heavy > 8.4oz

**3.5 형태 선호 (preferred_shapes)** — 선택 시에만. 선호 형태면 1, 아니면 0.4(강제 제외가 아니라 점수 차이)

## 4. 합산
`총점 = Σ(가중치 × 축점수) / Σ(활성 축의 가중치) × 100`
| 축 | 가중치 |
|---|---|
| power_control | 0.35 |
| forgiveness | beginner 0.30 / intermediate 0.15 / advanced 0.05 |
| arm_comfort | arm_discomfort일 때 0.35, 아니면 제외 |
| weight_preference | 선택했을 때 0.15 |
| shape_preference | 선택했을 때 0.15 |

- 동점이면 id 오름차순(결과가 항상 같게).
- 총점은 내부 값이다. 화면에는 숫자 대신 라벨로 보여 준다: 80 이상 "매우 잘 맞음", 60~79 "잘 맞음", 그 미만 "보통"(거짓 정밀도 방지).
- 상위 3개를 보여 준다. 후보가 3개 미만이면 있는 만큼만 보여 준다.

## 5. 추천 이유와 주의 문구
- 각 축은 점수와 함께 `reason`(규칙 ID + 값)을 낸다. 이유 문장은 규칙 ID별 템플릿이다. 예: "코어가 {core}mm로 두꺼워 컨트롤과 안정감에 유리합니다".
- 기여가 큰 상위 2~3개 축을 이유로 보여 준다.
- 강한 감점 축(예: 팔 불편인데 무거운 패들)은 **주의 문구**로 따로 보여 준다. 좋은 점만 말하지 않는다.
- 제휴 링크는 점수와 이유에 영향을 주지 않는다. 엔진은 링크 필드를 읽지 않는다(purity 테스트가 지킨다).

## 6. 결과가 없을 때: 조건 완화 힌트
하드 필터 후 후보가 0개면 빈 화면 대신 "예산을 N원 올리면 M개", "대회 인증 조건을 빼면 K개"처럼 **어떤 조건이 걸림돌인지** 보여 준다. 각 조건을 하나씩 풀어 개수를 센다.

## 7. 검증 계획
- **속성 테스트**: 모든 축은 0~1. 같은 입력은 항상 같은 결과. 코어가 두꺼울수록 control 선호 사용자의 power_control 적합도는 내려가지 않는다(단조성) 같은 방향 성질.
- **골든 페르소나 테스트**: 성향이 뚜렷한 가짜 제품 4~5종(파워형, 컨트롤형, 가볍고 얇은 형, 넓고 두꺼운 형 등)과 대표 사용자 10~15명(초보, 팔 불편, 파워 선호 등)을 정해 "기대 1순위"를 고정한다. 실제 제품명은 쓰지 않는다.
- **실제 데이터 확보 후**: 대표 사용자에게 나온 상위 3개를 사람이 훑어 상식에 맞는지 확인하고, 임계값을 조정한 뒤 `SCORING_VERSION`을 올린다.

## 8. 작업 분해
- T-003 프로필 확장 (스키마와 한국어 검증 메시지)
- T-004 점수 축 순수 함수와 설정 파일, 속성 테스트
- T-005 `recommend()` 조립, 이유 템플릿, 조건 완화 힌트, 골든 페르소나 테스트

## 9. 사용자 확인이 필요한 결정
1. 질문 5개(경력, 플레이 성향, 무게 선호, 팔 불편, 선호 형태)로 충분한가
2. 점수는 숫자 대신 라벨로 보여 주는가
3. 초기 임계값을 가설로 두고 실제 데이터로 보정하는 방식에 동의하는가
4. 성별과 그립 크기를 점수에서 제외하는가
5. 추천 개수는 3개 + 조건 완화 힌트로 하는가

## 10. 변경 이력
### v0.2.0 (2026-11-15) 경력별 무게 적합 축 추가 (D-021)
- **3.6 경력별 무게 적합 (skill_weight)**: 초보·중급에게만 계산한다. 권장 무게대(7.3~8.4oz) 안이면 1, 벗어난 만큼 1oz당 2.0 감점(하한 0). 사용자가 무게 선호를 직접 골랐으면 계산하지 않는다(무게 선호 축이 대신함).
- 가중치: beginner 0.20, intermediate 0.10, advanced 제외.
- 추가한 이유: 실제 제품 데이터로 처음 돌렸을 때 초보·균형 사용자에게 8.75oz 패들이 1순위로 나왔다.
- 확인: 실제 제품 19개에서 초보·균형 1순위가 8.11oz 넓은 형으로 바뀌었고, 8.82oz 제품에는 "무거운 편" 주의 문구가 붙는다.
- 남은 약점: 상급·파워 사용자에게 입문용 ProKennex Power(9.9만 원)가 1순위로 나온다. 판매처가 적은 "패들두께 13mm"를 코어 두께로 넣은 탓에 얇은 코어의 파워형으로 계산된다. 데이터 문제이며 점수 공식 문제가 아니다.
