## 기획안 PDF 요약(PaddleFit | 서비스 고도화 기획안, Concept v1.0, 2026-11-17, 5쪽)
- 목적: 1분 설문 → 패들 3개 추천 핵심 경험 유지, 선택 신뢰성과 탐색·비교 강화
- 원칙: 회원가입 금지, 추천 근거를 구조화 데이터로, 광고·제휴 표기와 순위 산정 분리, 승인 출처·확인일·미확인 구분
- 디자인 컨셉: Sports × Commerce. 짙은 네이비/코트 틸, 액티브 라임 포인트, 밝은 제품 비교 영역. 제조사 이미지 사용 권한 검토 필요
- 정보 구조: 홈(히어로·3단계·결과 미리보기·신뢰 근거) / 설문(7단계 진행률·선택 카드·뒤로·응답 유지) / 결과(성향 요약·TOP3·이유/주의점·근거 출처 → 비교) / 제품 탐색(브랜드·가격·무게·형태 필터·정렬) / 비교(최대 3개, 스펙·장단점·출처/기준일)
- 백로그: P0 설문 UX·추천 설명·데이터 신뢰(스펙 출처 URL·수집일·검증일·미확인)·반응형(360px~데스크톱) / P1 비교(최대 3개 선택, 차이 강조)·필터·검색(가격/무게/형태/두께/브랜드, 초기화)·결과 저장(로그인 없이 로컬, 공유 링크 별도)·피드백(적합/부적합 이유, 개인정보 최소화) / P2 프로필(동의 기반)·가격/구매 연결(업데이트일·제휴 표기)
- 추천 엔진: 근거 없는 "95% 적합도" 금지, 선호 관계는 가설로 관리, TOP3 다양성 규칙(적합형·대안형·예산형) 시험, 누락 정보는 "정보 미확인"·신뢰도 저하, 추천 평가(전문가 시나리오 20~30개·일관성·민감도·커버리지·사용자 성과)
- 데이터: Paddle / SpecificationSource(필드별 출처·관측일·검증일·신뢰도) / Approval / RecommendationRun / Feedback
- 로드맵: 현황 파악 → UI 시스템(토큰·반응형 시안, 디자인 승인) → P0 → P1 → 운영 검증. 지표 기준값 수집 전 목표치 확정 금지. 성능(LCP/CLS/INP)·법무(이미지·상표·승인 최신성·제휴 고지)

## 사용자 결정(D-035, 2026-11-17)
1. 이미지: 직접 그린 패들 그림을 정교하게 + 히어로·배경은 상업 이용 가능한 스톡 사진(사용자가 골라 구입). 제조사 사진 쓰지 않음
2. "AI 맞춤 추천·AI 분석" 표현 쓰지 않음
3. 플레이 밸런스 레이더·제품별 특성 막대(컨트롤·파워·스핀·안정성·기동성): 출처 있는 특성 데이터를 확보한 뒤에
4. 범위: M3 앞에 리디자인 단계. 색·헤더·홈·결과 데스크톱 2단·모바일 화면 + P1 일부(로컬 결과 저장, 브랜드·무게 필터·검색, 둘러보기에서 비교 담기). 쿠팡·측정·피드백은 M3
